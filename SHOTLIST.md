# Shot list

Fourteen textures. Download each one, **save it under the exact filename in the
first column**, drop it in `assets/textures/`, and re-run `npm run render`.

Everything here is **Unsplash**, under the [Unsplash Licence](https://unsplash.com/license)
— free, commercial use permitted, no attribution required. Nothing needs a
Shutterstock credit, and nothing here is editorial-only.

Every texture is deliberately generic. The identifiable car in each poster stays
vector, so none of these has to be a particular model — which is also why they
are all cleanly licensable.

> Picks were made from photographer descriptions and titles, not by opening each
> frame. Check the candidate against the **Looking for** column before committing
> to it; where a pick is wrong, the browse link beside it is the shortest route
> to a better one.

## Priority

If you only do some, these five change the posters most:
`night-carpark`, `light-trails`, `terrain-mud`, `city-bokeh-night`, `mountain-mist`.
The rest are subtle grounds and stocks.

## Optional: real branded hero cars

Not needed for the direction we settled on — the vector car is the hero, and it stays accurate to
the badge on the poster. But the per-car photo slots still work, and Unsplash does carry real,
identifiable cars under the same free commercial licence.

Save as `assets/cars/<slug>.jpg` (a rectangular photo) or `assets/cars/<slug>-cutout.png`
(background removed, for the free-floating hero). Slugs are in `src/data/cars.js`.

Confirmed available for the Porsche:

- https://unsplash.com/photos/silver-porsche-911-on-road-during-daytime-NeH9w4CdmnA
- https://unsplash.com/photos/porsche-sports-car-in-modern-showroom-2Bjo1lzZlHc
- https://unsplash.com/photos/black-car-in-grayscale-photography-vQVWIsIBafA

For the others, search `https://unsplash.com/s/photos/<make>-<model>` — e.g.
`/s/photos/jeep-wrangler`, `/s/photos/bmw-m5`, `/s/photos/ford-mustang`.

⚠ A photo of a real car is licensed; the **trademarks in it are not**. `NOTICE.md` covers this —
the same caution that applies to the drawn logos applies to a badge visible in a photograph.

git push origin claude/car-social-graphics-1abcet

PNGs back. Or render locally with `npm run render`.
